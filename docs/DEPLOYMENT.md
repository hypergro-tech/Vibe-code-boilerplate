# Deployment

## 🌐 Your app is live at
_Not deployed yet._ Run **`npm run deploy`** from the project root and this file
will fill in automatically with your live web address.

---

## Ship a new version
```bash
npm run deploy
```
Same command, same URL — a new version goes live in a couple of minutes.

## Undo a bad change (rollback)
```bash
npm run rollback
```
Pick a version from the list — traffic switches back instantly, no rebuild.

## See what your live app is doing (logs)
```bash
npm run logs
```

> After your first deploy, this file is updated automatically (live URL, current
> version, GitHub repo). Don't edit it by hand.
